## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately.

Please do not disclose security issues through public GitHub issues, discussions, or pull requests.

Instead, please:

1. Open a private security advisory on GitHub if available under the **Security** tab.
2. Alternatively, reach out directly to the repository maintainer via their GitHub profile [@bmotana](https://github.com/bmotana).

Please include:

- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
- Any suggested fixes or mitigations.

We appreciate your responsible disclosure and will respond as quickly as possible.
